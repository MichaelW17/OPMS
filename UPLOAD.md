# Repository synchronization

Target repository: https://github.com/MichaelW17/OPMS

This folder is a Git checkout. The existing Apache-2.0 license is preserved. Use authenticated Git to upload committed changes. Fetch and integrate remote updates before pushing; no force push is required.

The release contains source code, English usage documentation, archived data, and reproduced figures. Raw powers are compressed into eight NPZ archives; the largest file is approximately 42.4 MB. The complete data collection is approximately 487 MB. Temporary simulations and Python caches are excluded by `.gitignore`.
